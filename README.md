## ⚙️ Como Executar Localmente

### Pré-requisitos
- Node.js 18+ (recomendado Node 20 ou 22)
- npm ou pnpm

### Passos

1. Clone o repositório ou acesse a pasta:
```bash
git clone https://github.com/teusbraga/CV-Mateus-Almeida.git
cd CV-Mateus-Almeida
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## 🚀 Deploy na Vercel

O projeto foi construído para deploy com 1 clique na **Vercel**:

1. Crie um repositório no seu GitHub (`CV-Mateus-Almeida`).
2. Acesse [vercel.com](https://vercel.com) e clique em **Add New Project**.
3. Importe o repositório. O Next.js será detectado automaticamente.
4. Clique em **Deploy**.
